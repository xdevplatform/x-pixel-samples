# X Pixel samples

The [X Pixel](https://help.x.com/en/business-and-advertising/conversion-tracking-for-websites) is the conversion tracking tag for X Ads. Advertisers add it to their website to measure the actions people take after seeing or clicking their ads, such as sign-ups and purchases.

This repository has samples for adding the X Pixel to your site.

## Samples

- [Next.js](nextjs): App Router and TypeScript

## Resources

- [Conversion tracking for websites](https://help.x.com/en/business-and-advertising/conversion-tracking-for-websites): set up the pixel and events in Events Manager
- [X Pixel implementation best practices](https://help.x.com/en/business-and-advertising/about-conversion-tracking#x-pixel-implementation-best-practices): where to place the code and how to verify it
- [X Pixel Helper](https://chromewebstore.google.com/detail/x-pixel-helper/jepminnlebllinfmkhfbkpckogoiefpd): Chrome extension to check that the pixel and events fire
- [Conversion API](https://docs.x.com/x-ads-api/measurement/web-conversions): send conversions from your server
